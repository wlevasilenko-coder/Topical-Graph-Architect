# Migration notes v4.0.8 -> v4.0.9

v4.0.9 is an editorial release that provides an English translation of the full TGA specification and minor wording clarifications. There are NO behaviour changes to module responsibilities or outputs compared to v4.0.8.

What changed:
- Added English SPECIFICATION-en.md and convenience copy Topical-Graph-Architect-v-4-0-9.md.
- Added English prompt templates in spec/prompts/.
- Added versioned permissive schemas tga-v4.0.9-input/output.

Migration guidance:
- Consumers of the output schema can continue to use tga-v4.0.8-output.schema.json until you adopt tga-v4.0.9 explicitly.
- If you use strict JSON validators with `additionalProperties: false`, update your validators to one of:
  - accept the new schema version, or
  - run a compatibility adapter that strips unknown fields, or
  - pin to the older schema and run a migration step.
